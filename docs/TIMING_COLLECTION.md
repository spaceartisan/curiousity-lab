# Local timing collection

With activity history enabled, newly created attempts use optional `timing` version 1 with `algorithm: visible-interaction-60s-v2`, `coverage: from-start` and nonnegative `pausedMs`. Legacy or already-started drafts observed after an upgrade/history enablement start partial. Legacy active totals are retained, so partial coverage does not claim all prior time used this algorithm. Existing backups without timing remain valid.

The clock uses monotonic `performance.now()` differences. Active time requires the selected unfinished activity, a visible document, no explicit pause, and at most 60 seconds since open/resume/return or pointer/key interaction. Input contents are never retained. Close the old interval before an input renews recency, so a long idle gap cannot become active retrospectively. Explicit pause accumulates only while the selected activity is visible. Hidden, offscreen, idle and closed time are excluded, not inferred as pauses. An explicit resume or document return opens a fresh idle window.

Drain before finish, mode/content/replay boundaries, navigation and visibility/pause changes. Each slice carries the original game and draft ID; stale slices cannot enter a successor or finalized attempt. Finalized records round active/pause totals to milliseconds; drafts retain fractions. One-second sampling checkpoints open activity, and pagehide requests a best-effort immediate save in state-update order. Abrupt OS/browser termination or storage failure can lose the uncommitted tail; neither browser timestamps nor successful delivery are independently verified. Closing and reopening a tab never adds closed time.

History-off collects no optional timing or summaries. Clear-history also purges timing from drafts and durable recovery copies while keeping necessary game progress. JSON retains exact timing, CSV appends a quoted timing JSON column (unknown blank), and only validated timing enters local Insights preparation. Companion gets no timing or raw metrics. No private activity upload is enabled.

`local-context-review-5` separates missing/partial/from-start timing coverage and algorithms along with the existing task/presentation context. Pause amounts are outcomes, not grouping keys. Known pause ranges use recorded sessions only; missing is not zero. The raw table keeps exact source active and pause milliseconds. Active plus known pause exceeding wall-clock elapsed duration (1 ms rounding tolerance), or a reversed start/end, is flagged without repairing source values. No trend, health or enjoyment interpretation is made.
