# Chosen phrase reasoning

Four original Classic phrases retain their exact content, indices, authored IDs, mode and content versions. Four new Challenging phrases have five heard notes and a sixth note to choose. The rule is stated before play: alternating up-two/down-one steps, opposing interleaved lines, changing step lengths, or parallel interleaved lines. This is a specified sequencing task, not a claim that a finite musical phrase has only one possible continuation. A step means an adjacent white key on the existing C4–C5 keyboard, rather than a semitone. All heard and answer notes fit that range.

The player explicitly chooses the collection. Confirming replacement starts a fresh attempt and preserves the free-piano recording; canceling retains the current attempt. Another phrase cycles within that collection, and Try this exercise again repeats the same content with a new attempt. A different music activity starts its original first exercise. Staff, Note pattern and By ear remain available, with deliberate replay and no autoplay or penalty. By ear hides the visual sequence. Hint explains the exact rule application and answer only on request; a mismatched key gives no answer. Longer control instructions stay closed initially.

New challenging attempts use `phrase:challenging` mode and `music-phrases-2` content version. Previously filed records stay unchanged. Necessary progress and presentation resume with history off, without optional hint/timing accumulation. No raw audio, new upload or new cloud permissions are added. These are provisional game difficulty choices; perceived challenge, notation familiarity, actual family-device sound/accessibility and independent music-content review remain unverified.
